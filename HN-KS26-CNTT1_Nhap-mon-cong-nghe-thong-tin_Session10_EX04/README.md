# kết quả ai trả lời về mô hình ipo trong trang trại thông minh

## 1. mô hình ipo là gì

mô hình ipo là quy trình xử lý thông tin cơ bản gồm 3 phần
- input (đầu vào): thu thập dữ liệu từ thiết bị
- process (xử lý): máy tính tính toán và đưa ra quyết định
- output (đầu ra): thiết bị thực hiện hành động

---

## 2. ví dụ hệ thống tưới nước tự động

1. input (đầu vào): cảm biến độ ẩm cắm dưới đất đo được là 35% (đất đang khô)
2. process (xử lý): bộ điều khiển nhận dữ liệu 35%, so với mức chuẩn 60% thấy thiếu nước nên ra lệnh bật máy bơm
3. output (đầu ra): máy bơm tự động bật lên phun nước tưới cho rau

---

## 3. tóm tắt ghi nhớ

- input: cảm biến ghi nhận thông tin
- process: bộ não máy tính quyết định
- output: thiết bị hành động (bật đèn, quạt, máy bơm)

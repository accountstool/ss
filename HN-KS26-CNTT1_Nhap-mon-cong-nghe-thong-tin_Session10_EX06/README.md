# Dự Án Trang Trại Thông Minh GreenTech

## 1. Mục tiêu
- Tạo ra giải pháp công nghệ xanh tự động hóa trang trại
- Nâng cao ý thức cộng đồng về bảo vệ môi trường
- Phát triển nông nghiệp bền vững

## 2. Giới thiệu
GreenTech là dự án hướng tới việc ứng dụng công nghệ để bảo vệ môi trường, giúp cuộc sống xanh và bền vững. Hệ thống hỗ trợ theo dõi thông số môi trường và tự động hóa quy trình chăm sóc cây trồng cho trang trại Lan.

## 3. Quy tắc làm việc nhóm
1. Trước khi sửa: git pull
2. Sau khi sửa: git add, git commit, git push
3. Thường xuyên sync với main
4. Thảo luận trước khi đổi lớn

> *Ghi chú: Tài liệu được chuyển đổi sang chuẩn Markdown (.md) để hỗ trợ đọc trực tiếp trên GitHub và so sánh thay đổi chính xác khi làm việc nhóm.*
